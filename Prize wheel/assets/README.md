# Assets

Logos, ícones e imagens de marca para o projecto Zura Touch Prize Wheel.

## Estrutura

```
assets/
├── branding/     → Logos Zura Touch, Mystery Box, guidelines
├── icons/        → Ícones da app (fonte vectorial)
└── README.md
```

## Ícones e logo

- `branding/zura_touch_logo.png` — logo oficial Zura Touch (arco + wordmark branco/cinza)
- `icons/ic_launcher.xml` — ícone vectorial placeholder da app

## Uso

1. Coloca aqui os ficheiros de design (SVG, PNG, AI, Figma exports)
2. Copia/adapta para `android/app/src/main/res/` quando fores actualizar a app

## Cores de marca

| Nome | Hex | Uso |
|------|-----|-----|
| Background | `#101828` | Fundo principal |
| Accent | `#FDB022` | Botões, destaques |
| Mid blue | `#344A78` | Gradiente |
