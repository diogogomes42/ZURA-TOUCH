# Protótipo web

Protótipo HTML/CSS/JS usado como referência visual para a roda de prémios na app Android.

## Como ver

Abre `index.html` no browser (duplo-clique ou servidor local):

```bash
# Opcional: servidor local
npx serve .
```

## O que demonstra

- Layout e cores da Mystery Box
- Animação de spin (~4.2s)
- Fluxo simulado: pagamento → spin → dispense → reveal
- Preço €2.00 e categorias de prémio

## Nota

Este protótipo **não** está ligado à máquina nem à app Android — serve apenas como mockup de design.
